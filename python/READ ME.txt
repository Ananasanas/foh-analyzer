FOH Analyzer - Python desktop version 1.1
=========================================

What it does
- Live tab: RTA (1/1 to 1/24 octave) and high-resolution FFT spectrum (View: RTA + spectrum,
  RTA bars or Spectrum), scrolling spectrograph, averaging, peak hold and freeze, about 30 fps;
  SPL meter A/C/Z with Fast/Slow/Impulse, Leq, Max and Peak; 60 s SPL history;
  Mix advisor (feedback/ringing, mud, boom, harsh, sibilance, dull top, clipping, low dynamics).
  Tips stay on screen 5/15/30/60 s after the problem clears; the advisor can be hidden.
- Calibrate mic...: acoustic calibrator (94/104/114 dB at 1 kHz or 250 Hz), match a trusted
  SPL meter, manual offset, or load your measurement mic's calibration file (UMIK-1 etc.).
  Saved per input device in your home folder (.foh_analyzer.json).
- Room tab: sweep measurement (speaker + mic) or a simulated room. Frequency response, decay
  curves, T20/T30/EDT, C50/C80/D50, background noise, room advisor and a 9-step walkthrough.
- Crowd mic delay tab: two-channel delay finder (input 1 = band mix, input 2 = crowd mic) with
  polarity check, distance calculator, crowd mic list and the General / DiGiCo S21 walkthroughs.
  The S21 steps include screenshots from the DiGiCo offline editor (click to enlarge).

Windows: how to start
1. Install Python 3 from https://www.python.org/downloads/ (tick "Add python.exe to PATH").
2. Unzip this folder anywhere (for example to the Desktop).
3. Double-click "Start FOH Analyzer.bat". The first start needs internet to install numpy and
   sounddevice (about a minute). After that it starts straight away and works offline.

macOS / Linux: run ./start.sh in a terminal (needs python3; on Linux also python3-tk).

Without a microphone, pick "Demo mix", "Pink noise", "WAV file..." or "Simulated crowd mic"
in Source to try everything.

Notes
- SPL numbers are only real after you calibrate (until then an assumed offset is used).
- For the crowd mic delay finder the audio interface must give two separate input channels.
- This version has not yet been tested with real audio hardware.
